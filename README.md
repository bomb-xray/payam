# 💬 پیام

پیام‌رسان وب با احراز هویت از طریق **بات تلگرام** — بدون نیاز به سامانه‌ی پیامکی.

## ویژگی‌ها

- 🔑 ورود با آی‌دی عددی تلگرام + کد یک‌بارمصرف که بات ارسال می‌کند (یا ورود با یک کلیک از طریق دیپ‌لینک)
- 💬 چت دونفره‌ی زنده با WebSocket
- ✓✓ تیک تحویل و خوانده‌شدن پیام‌ها
- 🟢 وضعیت آنلاین / آخرین بازدید
- ⌨️ نشانگر «در حال نوشتن…»
- 🔍 جستجوی کاربران، نشان پیام‌های نخوانده
- 📦 دیتابیس SQLite (بدون نیاز به نصب دیتابیس جدا)
- 📱 رابط کاربری فارسی، راست‌به‌چپ، ریسپانسیو (موبایل و دسکتاپ)

## فلو احراز هویت

1. کاربر در صفحه‌ی ورود، آی‌دی عددی تلگرامش را وارد می‌کند (دریافت آن با دستور `/id` در بات).
2. سرور یک کد ۵ رقمی یک‌بارمصرف می‌سازد و از طریق بات به تلگرام کاربر می‌فرستد.
3. کاربر کد را در سایت وارد می‌کند **یا** روی لینک «ورود سریع» می‌زند (بات `/start <token>` را دریافت و ورود را کامل می‌کند).
4. هر کد به سیشنِ لاگینِ خودش گره خورده، ۵ دقیقه اعتبار دارد و فقط یک‌بار مصرف می‌شود.

## اجرای محلی

```bash
npm install
npm run build
cp .env.example .env
# توکن بات را در .env قرار دهید (BOT_TOKEN=...)
npm start
```

سپس در مرورگر باز کنید: `http://localhost:3000`

حالت توسعه (بدون build):

```bash
npm run dev
```

## دیپلوی روی VPS

فایل سرویس systemd در `deploy/payam.service` آماده است:

```bash
sudo cp deploy/payam.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now payam
```

> مسیر پیش‌فرض سرویس `/opt/payam` است و توکن را از `/opt/payam/.env` می‌خواند.

## بات تلگرام

- دستورات: `/id` (آی‌دی عددی)، `/start <token>` (ورود سریع با لینک)
- حالت long polling است؛ نیازی به webhook و دامنه نیست.
- اگر توکن اشتباه باشد یا تلگرام در دسترس نباشد، سرور هر چند ثانیه دوباره تلاش می‌کند.

## ساختار پروژه

```
src/
  index.ts    نقطه‌ی ورود سرور
  config.ts   بارگذاری تنظیمات (.env)
  db.ts       SQLite + کوئری‌ها
  auth.ts     منطق کدها، سشن‌ها، ریت‌لیمیت
  bot.ts      بات تلگرام (grammY)
  api.ts      APIهای HTTP
  ws.ts       سرور WebSocket (چت، حضور، تیک‌ها)
public/       کلاینت وب (HTML/CSS/JS خالص)
deploy/       فایل سرویس systemd
```

## امنیت

- توکن‌های سیشن به‌صورت هش SHA-256 ذخیره می‌شوند.
- هر کد ورود فقط برای همان سیشنی که درخواست داده اعتبار دارد (جلوگیری از جابه‌جایی کد).
- ریت‌لیمیت: هر آی‌دی ۳ بار در ۱۰ دقیقه، هر آی‌پی ۱۵ بار در ۳۰ دقیقه.
- متن پیام‌ها سمت کلاینت با `textContent` رندر می‌شود (ضد XSS).
- ⚠️ توکن بات را هیچ‌وقت در گیت قرار ندهید (`.env` در `.gitignore` است).
